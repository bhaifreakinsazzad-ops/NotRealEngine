## Defects addressed
1. Password-reset email used to route customers into settings rather than a password-change form. Added authenticated /reset-password form, server action and sign-out after successful change.
2. Auth callback accepted unvalidated next paths. Added safe internal redirect allowlist, used throughout login and callback.
3. Protected /admin login and sign-in return path mismatched. Preserve validated route destinations.
4. Anonymous configuration drafts previously allowed a raw arbitrary persisted payload. Added strict typed validation, reasonable length bounds and regression coverage.
5. Claimed configuration drafts previously remained retrievable using only their original bearer token. GET now requires authenticated original owner after claim.
6. Draft token validation strengthened. Existing upstream service-role and membership-checked claim implementation retained.
7. Narrow viewport UI: engine showcase telemetry, consult call-to-action flex wrapping, admin quote editor and project workspace panels.
8. Security headers: explicit X-Frame-Options and HTTPS HSTS.
9. Admin Settings RLS table count copy corrected so it does not claim an inaccurate fixed count.
